🌐 Lite 版本使用说明

Lite 版完全运行在浏览器中，所有数据保存在本地内存，不会上传至任何服务器。

方式一：直接打开

用浏览器直接打开 sci-plotter-lite/index.html

方式二：启动本地静态服务器（推荐）

$ cd sci-plotter-lite
$ python -m http.server 8080
# 然后访问 http://localhost:8080
提示：部分浏览器在 file:// 协议下会限制 Fabric.js 的图片跨域加载，使用本地服务器可避免此问题。

🖥️ 完整版本地部署指南

Desktop 版基于 Python + PyWebView，与 Lite 版共用同一套前端代码，额外提供本地文件系统、统计分析、矢量导出等能力。

环境要求

  • Python >= 3.10
  • 操作系统：Windows / macOS / Linux

步骤 1：安装 Pixi（若尚未安装）

$ powershell -c "irm https://pixi.sh/install.ps1 | iex" # Windows
$ curl -fsSL https://pixi.sh/install.sh | bash # macOS / Linux

步骤 2：克隆仓库并安装环境

$ git clone https://github.com/DavidNiteas/SCI-Plotter.git
$ cd SCI-Plotter
$ pixi install
说明：本项目已配置 pixi.toml，执行 pixi install 后会自动创建虚拟环境，并以开发模式（editable）安装 sci-plotter 及其所有依赖。

步骤 3：启动 Desktop 应用（开发模式）

$ pixi run dev
# 等价于：sci-plotter --dev（直接引用外部 sci-plotter-lite 目录，无需同步资源）

常用命令

$ pixi run dev # 启动桌面应用（开发模式）
$ pixi run test # 运行 pytest 测试
$ pixi run lint # 运行 ruff 代码检查
$ pixi run format # 运行 ruff 代码格式化
$ pixi shell # 进入项目虚拟环境

生产模式部署（可选）

$ cd sci-plotter
$ python scripts/sync_assets.py # 同步前端资源到 assets/
$ sci-plotter # 启动生产模式
提示：生产模式下应用会加载已同步的静态资源，无需依赖外部 sci-plotter-lite 目录。
