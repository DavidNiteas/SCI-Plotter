# Lite 版使用指南

> 零安装，浏览器打开即用。适合快速出图和跨设备协作。

## 启动方式

### 方式一：直接打开（最快）

1. 进入 `sci-plotter-lite/` 目录
2. 用浏览器直接打开 `index.html`

推荐使用 Chrome、Edge、Firefox 等现代浏览器。

### 方式二：本地服务器（推荐）

部分浏览器在 `file://` 协议下会限制文件读取，建议启动本地服务器：

```bash
cd sci-plotter-lite
python -m http.server 8080
```

访问 [http://localhost:8080](http://localhost:8080)。

## 三步完成第一张图

### 第一步：导入数据

1. 打开后默认进入**数据管理**页面
2. 点击左侧**「导入 CSV」**按钮，选择你的 CSV 文件
   - 也可直接使用 `demo/` 目录下的示例数据练习
3. 数据会自动解析并显示在表格中
4. 可在表格中直接双击单元格编辑数据

**支持的 CSV 格式：**
- 逗号 `,`、制表符 `\t`、分号 `;`、竖线 `|` 分隔均可自动识别
- 第一行为列名
- 数字会自动识别为数值类型

### 第二步：创建子图

1. 点击底部 Dock 切换到**子图编辑**页面
2. 左侧选择刚导入的**数据表**
3. 点击**图表模板**卡片选择图表类型（18 种模板可选）
4. 在左侧调整：
   - **数据列映射** — 选择 X 轴、Y 轴对应的列
   - **配色方案** — 内置 Nature、Science、Viridis 等科研配色
   - **误差棒** — 可选，支持数据列误差、固定值、百分比、标准差
   - **趋势线** — 可选，支持线性、多项式、指数、对数、幂函数拟合
5. 在图表下方可使用**绘图工具**添加矩形、圆形、直线、文本标注

### 第三步：排版与导出

1. 点击**「暂存当前子图」**保存当前子图到快照库
2. 切换到**主图排版**页面
3. 从左侧快照库拖拽子图到画布
4. 自由调整子图位置、大小
5. 点击顶部**「导出」**按钮，选择：
   - **PNG / JPEG** — 光栅图，支持 1x~4x DPI
   - **工作区备份** — `.json` 全量保存，下次继续编辑
   - **可编辑图文件** — `.spf` 自包含格式

## 分析工作台（可选）

如果需要在绘图前对数据做预处理：

1. 切换到**分析工作台**页面
2. 选择源数据表，勾选需要分析的列
3. 可用功能：
   - **数据过滤** — 按条件筛选行
   - **排序** — 按指定列升序/降序
   - **缺失值处理** — 删除行、填充均值/中位数/众数/固定值、前后向填充
   - **数据标准化** — Z-score、Min-Max、MaxAbs、Robust、Log 变换
   - **计算新列** — 双列运算、单列函数、统计变换
   - **统计分析** — 12 种方法（t 检验、ANOVA、回归等），使用 JavaScript 引擎
4. 点击**「生成并保存」**将处理结果保存为新数据表

## 工作区管理

| 操作 | 方式 |
|------|------|
| 保存工作区 | `Ctrl + S` 或点击顶部按钮，下载 `.json` 文件 |
| 打开工作区 | 点击顶部「打开工作区」按钮，选择之前保存的 `.json` 文件 |
| 导出数据 | `Ctrl + E` 或点击顶部「导出」按钮 |

工作区文件包含所有数据表、子图快照、主图排版状态，可在 Lite 与 Desktop 版之间互通。

---

## Lite 版使用限制

| 限制 | 说明 |
|------|------|
| 无矢量导出 | 不支持 SVG / PDF 导出，需使用 Desktop 版 |
| 无自动保存 | 数据仅保存在浏览器内存中，刷新页面会丢失 |
| 文件上传方式 | 通过浏览器 `<input>` 上传，非原生文件对话框 |
| Excel 依赖网络 | SheetJS 库通过 CDN 加载，需网络连接 |

如需上述功能，请使用 [Desktop 版](desktop-guide.md)。

| `Ctrl + Shift + Z` | 重做 |

| `Ctrl + C / V / X` | 复制 / 粘贴 / 剪切（表格单元格） |
| `Ctrl + A` | 全选（表格） |
| `Delete` | 删除选中内容 |
