# 快速上手

> 5 分钟内完成第一张科研图。无论你选择 Lite 版还是 Desktop 版，本文档将引导你快速走通完整工作流。

## 选择你的版本

| 版本 | 启动方式 | 适合场景 |
|------|---------|---------|
| [Lite 版](#lite-版) | 浏览器打开 `index.html` | 快速出图、免安装体验 |
| [Desktop 版](#desktop-版) | `pip install sci-plotter` | 统计分析、矢量导出、论文出版 |

两套版本共用同一套前端界面，数据格式完全兼容，可随时切换。

---

## Lite 版

### 启动

```bash
cd sci-plotter-lite
python -m http.server 8080
```

访问 [http://localhost:8080](http://localhost:8080)。也可直接用浏览器打开 `index.html`。

### 四步出图

#### 第一步：导入数据

1. 打开后默认进入**数据管理**页面
2. 点击左侧**「导入 CSV」**按钮，选择 CSV 文件
3. 也可直接使用 `demo/` 目录下的示例数据练习

支持的 CSV 分隔符：逗号、制表符、分号、竖线，自动识别。

#### 第二步：（可选）数据预处理

1. 切换到**分析工作台**页面
2. 选择源数据表，勾选需要分析的列
3. 使用过滤、排序、缺失值处理、计算新列等功能预处理数据
4. 点击**「生成并保存」**创建处理后的新数据表

#### 第三步：绘制子图

1. 切换到**子图编辑**页面
2. 选择数据表 → 点击图表模板（散点、折线、柱状等 18 种模板）
3. 调整配色方案、坐标轴、误差棒、趋势线
4. 使用绘图工具添加矩形、箭头、文本等标注
5. 点击**「暂存当前子图」**保存到快照库

#### 第四步：排版与导出

1. 切换到**主图排版**页面
2. 从左侧快照库拖拽子图到画布
3. 调整位置、大小，添加文本和图形
4. 点击**「导出」**，选择格式：
   - **PNG / JPEG** — 光栅图，支持 1x~4x DPI
   - **工作区备份** — `.json` 全量保存，下次继续编辑
   - **可编辑图文件** — `.spf` 自包含格式

## Desktop 版

### 安装与启动

**要求：** Python >= 3.10

```bash
pip install sci-plotter
sci-plotter
```

启动后打开桌面窗口（默认 1400×900），界面与 Lite 版一致。

### 完整工作流

Desktop 版的四步工作流与 Lite 版完全相同，但提供以下增强能力：

| 环节 | Desktop 增强功能 |
|------|-----------------|
| 数据导入 | 弹出系统原生文件对话框，支持 CSV 和 Excel |
| 数据分析 | 12 种统计方法（t 检验、ANOVA、回归等），Python 后端驱动 |
| 自动保存 | 自动保存到 `~/.sci-plotter/autosave.json`，下次启动自动恢复 |
| 导出 | 额外支持 SVG / PDF 矢量图、PDF 报告 |

### 开发模式

从源码开发时，使用开发模式直接引用外部前端资源：

```bash
sci-plotter --dev
sci-plotter --dev --debug --port 8080
```

## 四窗口工作流一览

无论使用哪个版本，核心工作流一致：

| 页面 | 功能 | 关键操作 |
|------|------|---------|
| 数据管理 | 数据导入与管理 | 导入 CSV/Excel、手动建表、单元格编辑 |
| 分析工作台 | 预处理与统计 | 过滤、排序、计算新列、统计分析 |
| 子图编辑 | 单图绘制 | 选择模板、映射数据列、配色、标注 |
| 主图排版 | 多图组合与导出 | 拖拽子图、添加文本、导出图片 |
