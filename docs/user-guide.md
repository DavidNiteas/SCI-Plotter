## 界面概览

SCI-Plotter 采用**四窗口工作流**，通过底部 Dock 栏切换页面：

| 页面 | 功能定位 | 核心操作 |
|------|----------|----------|
| 数据管理 | 数据导入、编辑与管理 | 导入 CSV/Excel、手动建表、单元格编辑 |
| 分析工作台 | 数据预处理与统计分析 | 过滤、排序、计算新列、假设检验、回归 |
| 子图编辑 | 单图绘制与样式调整 | 选择模板、映射数据列、添加标注与图形 |
| 主图排版 | 多图组合与最终排版 | 拖拽子图、调整布局、添加文本、导出 |

顶部工具栏提供**保存**、**打开工作区**和**导出**按钮。所有操作都支持**撤销/重做**（`Ctrl+Z` / `Ctrl+Shift+Z`）。

## 数据管理

数据管理是整个工作流的起点，负责数据的导入、编辑、组织与导出。

### 导入数据

#### CSV 文件

点击左侧**「导入 CSV」**按钮，选择 CSV 文件。系统会自动检测分隔符类型：

- 逗号 `,`
- 制表符 `\t`
- 分号 `;`
- 竖线 `|`

第一行自动识别为列名，数字字段自动转为数值类型，空单元格存储为 `null`。

#### Excel 文件

点击**「导入 Excel」**按钮，选择 `.xlsx` 或 `.xls` 文件。如果文件包含多个工作表，每个工作表会自动创建为独立的数据表。

> Lite 版需要网络连接以加载 SheetJS 库；Desktop 版内置支持。

#### 手动新建

点击**「新建空表」**按钮，输入表名即可创建空白数据表，随后在表格中手动录入数据。

#### 示例数据

`demo/` 目录提供 6 组示例 CSV 文件，可直接导入体验各种图表类型：

| 文件 | 用途 |
|------|------|
| `scatter_demo.csv` | 散点图示例 |
| `line_demo.csv` | 折线图示例 |
| `bar_demo.csv` | 柱状图示例 |
| `boxplot_demo.csv` | 箱线图示例 |
| `heatmap_demo.csv` | 热力图示例 |
| `histogram_demo.csv` | 直方图示例 |

### 编辑数据

数据表格支持类似电子表格的操作方式：

| 操作 | 方式 |
|------|------|
| 编辑单元格 | 双击单元格，输入新值，按 `Enter` 确认 |
| 选区 | 单击选中单元格，拖拽或 `Shift+点击` 扩展选区 |
| 复制/剪切/粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`，支持跨表粘贴 |
| 全选 | `Ctrl+A` |
| 删除内容 | 选中后按 `Delete` |
| 查找替换 | `Ctrl+F` 打开查找替换面板 |

### 管理数据表

左侧边栏显示所有数据表列表，支持以下操作：

- **切换**：点击表名切换当前查看的表
- **重命名**：双击表名输入新名称
- **删除**：点击表旁的删除按钮（会弹出确认对话框）
- **导出单表**：将当前表导出为 CSV 文件

### 导出全部数据

点击**「导出全部数据」**按钮，将所有数据表打包导出为 JSON 文件。

## 分析工作台

分析工作台提供数据预处理和统计分析功能，处理后的数据可以生成新的数据表用于后续绘图。

### 基本操作

1. 在**「源数据表」**下拉框中选择要分析的数据表
2. 在左侧列表中**勾选需要分析的列**
3. 下方会实时显示数据预览

### 数据预处理

#### 过滤

支持按条件筛选数据行：

1. 点击**「添加过滤条件」**
2. 选择列、运算符（等于、不等于、大于、小于、包含等）和值
3. 可添加多个条件组合使用
4. 点击条件旁的删除按钮移除

#### 排序

选择排序列和方向（升序/降序），预览数据会实时更新排序结果。

#### 缺失值处理

选择目标列和处理方式：

| 方法 | 说明 |
|------|------|
| 删除行 | 移除包含缺失值的行 |
| 填充均值 | 用列均值填充（仅数值列） |
| 填充中位数 | 用列中位数填充（仅数值列） |
| 填充众数 | 用列众数填充 |
| 填充固定值 | 用指定的固定值填充 |
| 前向填充 | 用前一个有效值填充 |
| 后向填充 | 用后一个有效值填充 |

#### 数据标准化

| 方法 | 说明 |
|------|------|
| Z-score | 标准化为均值 0、标准差 1 |
| Min-Max | 缩放到 [0, 1] 区间 |
| MaxAbs | 按最大绝对值缩放 |
| Robust | 基于中位数和四分位距的鲁棒标准化 |
| Log 变换 | 对数变换（ln） |

### 计算新列

支持三种模式创建计算列：

**双列运算**：选择两个数据列，执行加、减、乘、除四则运算。

**单列函数**：对一个数值列应用数学函数：

- 基础函数：`abs`, `sqrt`, `square`, `log`, `log10`, `exp`
- 三角函数：`sin`, `cos`, `tan`
- 舍入函数：`floor`, `ceil`, `round`

**统计变换**：基于列的统计量进行变换。

### 统计分析

在**「统计方法」**下拉框中选择分析方法，配置参数后点击**「运行分析」**。

| 方法 | 说明 | 参数要求 |
|------|------|----------|
| 描述性统计 | 均值、标准差、最小/最大值、四分位数 | ≥1 列数值 |
| 独立样本 t 检验 | 两组数据均值差异检验 | 1 列数值 + 1 列二分类 |
| Mann-Whitney U 检验 | 非参数两组差异检验 | 1 列数值 + 1 列二分类 |
| Wilcoxon 符号秩检验 | 配对样本非参数检验 | 2 列数值 |
| 单因素方差分析 (ANOVA) | 多组均值比较 | 1 列数值 + 1 列分类 |
| Kruskal-Wallis 检验 | 非参数多组比较 | 1 列数值 + 1 列分类 |
| 卡方独立性检验 | 分类变量关联检验 | 2 列分类 |
| 简单线性回归 | 单自变量线性拟合 | 2 列数值 |
| 多元线性回归 | 多自变量线性拟合 | ≥2 列数值 |
| 相关矩阵 | 变量间相关系数 | ≥2 列数值 |
| 正态性检验 | 数据正态性评估 (Shapiro-Wilk) | 1 列数值 |
| 异常值检测 | 基于 IQR 或 Z-score 识别异常值 | 1 列数值 |

分析结果同时提供**表格视图**和**图表视图**，图表可直接发送到子图编辑器继续加工。

> Lite 版内置完整的 JavaScript 统计引擎，所有 12 种方法均可在浏览器中运行。Desktop 版使用 Python 后端（pandas、scipy）执行分析。

### 生成新表

完成预处理和分析后，点击**「生成并保存」**，处理结果将保存为一张新的数据表，可在数据管理和子图编辑器中使用。

## 子图编辑

子图编辑器用于绘制单个图表，支持 18 种图表模板、丰富的样式调整和绘图标注工具。

### 选择数据表

在左侧**「数据表」**下拉框中选择要绑定的数据表。切换数据表后，列映射会自动重置。

### 图表模板

点击模板卡片选择图表类型：

| 模板 | 说明 | 数据列映射 |
|------|------|------------|
| 散点图 | 两列数值分布关系，支持分组着色 | X(数值) Y(数值) 分组(分类) |
| 折线图 | 趋势变化，第一列作 X 轴 | X(任意) Y(数值) 分组(分类) |
| 柱状图 | 数值比较 | X(任意) Y(数值) 分组(分类) |
| 分组柱状图 | 多组并列柱状 | X(分类) Y(数值) 分组(分类) |
| 分组折线图 | 多组折线 | X(分类) Y(数值) 分组(分类) |
| 箱线图 | 统计分布 | 分组(分类) 值(数值) |
| 热力图 | 矩阵数据可视化 | X(数值) Y(数值) 值(数值) |
| 直方图 | 频率分布 | X(数值) |
| 面积图 | 面积堆叠趋势 | X(任意) Y(数值) 分组(分类) |
| 堆叠柱状图 | 分类数据堆叠 | X(分类) Y(数值) 分组(分类) |
| 环形图 | 比例构成 | X(分类) Y(数值) |
| 雷达图 | 多维度比较 | 分组(分类) |
| 气泡图 | 三维散点 | X(数值) Y(数值) 值(数值) 分组(分类) |
| 相关矩阵 | 变量相关性热力图 | 自动使用全部数值列 |
| 小提琴图 | 分布密度 | 分组(分类) 值(数值) |
| 瀑布图 | 增减累积 | X(分类) Y(数值) |
| 哑铃图 | 两组对比 | X(分类) Y(数值) 分组(数值) |
| 平行坐标图 | 多维数据探索 | 分组(分类) |

### 数据列映射

根据所选模板，在左侧下拉框中指定 X 轴、Y 轴、分组列和值列对应的数据列。不同模板有不同的映射要求，下拉框会自动显示兼容的列。

内置 15 种科研配色方案：

| Science | Science 期刊风格 |

#### 字体与字号

- **字号**：可调节全局字号

#### 宽高比

支持预设和自定义宽高比：`4:3`、`16:9`、`1:1`、`3:4`、自定义。

#### 坐标轴配置

| 选项 | 说明 |
|------|------|

### 误差棒

展开**「误差棒」**面板启用：

| 类型 | 说明 |
|------|------|

| 固定值 | 所有数据点使用统一的固定误差值 |
| 百分比 | 按数据值的百分比计算误差 |

支持 Y 轴和 X 轴方向的误差棒。

### 趋势线

展开**「趋势线」**面板启用：

| 类型 | 说明 |
|------|------|

### 显著性标注

支持在图表上添加显著性标记（如 `*`, `**`, `***`, `ns`），用于标注统计检验结果。点击工具栏的显著性标注按钮后，依次点击两个要比较的位置，然后输入标注文本。

### 绘图工具

图表下方的绘图工具栏提供以下标注工具：

| 工具 | 说明 |
|------|------|
| 选择 | 选择并移动已绘制的图形 |
| 矩形 | 拖拽绘制矩形 |
| 圆形 | 拖拽绘制椭圆 |
| 直线 | 拖拽绘制直线 |
| 箭头 | 拖拽绘制带箭头的直线 |
| 文本 | 点击位置输入文本标注 |

每个图形支持调整颜色、线宽、透明度。

### 暂存与发送

- **暂存当前子图**：将当前子图保存为快照，存入快照库，可多次暂存保留不同版本
- **发送到主图**：直接将当前子图添加到主图画布

## 主图排版

主图排版页是最终输出的核心，基于 Fabric.js 实现自由画布，支持多图组合、精确对齐和期刊级排版。

### 画布设置

#### 期刊尺寸预设

支持主流学术期刊的图片尺寸：

| 期刊 | 单栏 | 双栏 |
|------|------|------|
| Nature | 336×448 px | 692×519 px |
| Science | 215×287 px | 454×340 px |
| PLOS | 321×428 px | 673×505 px |
| IEEE | 336×448 px | 695×522 px |
| Elsevier | 340×454 px | 718×539 px |
| ACS | 314×419 px | 673×505 px |

也可自定义画布宽度和高度。

#### 背景色

支持自定义画布背景颜色。

### 添加子图

#### 从快照库拖入

左侧快照库显示所有已暂存的子图，直接拖拽到画布上即可添加。

#### 从子图编辑器发送

在子图编辑页点击**「发送到主图」**，自动切换到主图页并添加子图。

### 图层管理

右侧图层列表显示画布上所有对象，支持：

| 操作 | 说明 |
|------|------|
| 选择 | 点击图层名选中对应画布对象 |
| 排序 | 拖拽图层调整前后层叠顺序 |
| 锁定 | 锁定图层防止误操作 |
| 删除 | 删除图层及其画布对象 |
| 重命名 | 双击图层名修改名称 |

### 画布操作

| 操作 | 方式 |
|------|------|
| 选择对象 | 点击画布上的对象 |
| 移动对象 | 拖拽对象 |
| 缩放对象 | 拖拽对象四角的缩放手柄 |
| 旋转对象 | 拖拽对象顶部的旋转手柄 |
| 画布缩放 | 使用缩放控件或鼠标滚轮 |
| 画布平移 | 按住 `Space` + 拖拽鼠标 |
| 删除对象 | 选中后按 `Delete` |

### 对齐辅助

#### 智能对齐线

拖拽对象时自动显示对齐辅助线，帮助精确对齐其他对象或画布边缘/中心。可通过工具栏开关启用/禁用。

### 子图自动编号

支持为主图中的每个子图自动添加编号标签：

| 选项 | 说明 |
|------|------|
| 编号格式 | `(a)`, `(A)`, `a)`, `A)`, `a.`, `Fig.a` 等 |
| 编号字号 | 可自定义编号字体大小 |
| 编号位置 | 子图的左上角等位置 |

添加新子图时自动递增编号。

### 绘图工具

主图排版页同样提供矩形、圆形、直线、箭头、文本等绘图工具，用于在画布上添加辅助标注。

### 属性面板

选中画布上的对象后，属性面板显示并可编辑该对象的位置（X、Y）、尺寸、旋转角度、透明度等属性。

### 导出图片

点击顶部**「导出」**按钮，选择导出格式：

| 格式 | 说明 | 可用版本 |
|------|------|----------|
| PNG | 光栅图，支持 1x/2x/3x/4x DPI | Lite + Desktop |
| JPEG | 光栅图，体积更小 | Lite + Desktop |
| SVG | 矢量图，无限缩放 | Desktop |
| PDF | 矢量 PDF | Desktop |
| PDF 报告 | 包含图表说明的完整报告 | Desktop |

## 工作区与文件管理

### 保存工作区

| 方式 | 说明 |
|------|------|
| `Ctrl + S` | 快捷键保存 |
| 顶部「保存」按钮 | 点击保存 |

工作区保存为 `.json` 文件，包含：

- 所有数据表（含 headers、rows）
- 子图快照库（含缩略图和完整 ECharts 配置）
- 主图画布状态（图层、对象位置、尺寸）

### 打开工作区

| 方式 | 说明 |
|------|------|

工作区文件在 Lite 与 Desktop 版之间完全兼容。版本不匹配时会在控制台发出警告，但会尝试兼容加载。

### 自动保存（仅 Desktop）

| 可编辑图 | `.spf` | 自包含描述性格式 | ✅ download | ✅ 文件对话框 |
| 全部数据表 | `.json` | 仅数据表 | ✅ download | ✅ 文件对话框 |
| 单表 CSV | `.csv` | 当前选中表 | ✅ download | ✅ 文件对话框 |
| PNG 图片 | `.png` | 支持 1x~4x DPI | ✅ | ✅ |
| JPEG 图片 | `.jpeg` | 有损压缩 | ✅ | ✅ |
| SVG 矢量图 | `.svg` | 无限缩放 | ❌ | ✅ |
| PDF 矢量图 | `.pdf` | 论文投稿 | ❌ | ✅ |
| PDF 报告 | `.pdf` | 包含说明的完整报告 | ❌ | ✅ |

## 最佳实践

### 数据准备

1. **先整理 CSV**：导入前确保数据格式规整——第一行为列名、数据列无混杂文本
2. **善用分析工作台**：绘图前利用过滤、排序、计算新列等功能预处理数据
3. **保留原始数据**：通过"生成新表"创建处理后副本，原始数据表不会被修改

### 图表绘制

1. **选择合适的模板**：散点图看分布、折线图看趋势、柱状图看比较、箱线图看统计分布
2. **使用科研配色**：投稿 Nature/Science 等期刊时，选用对应期刊的配色方案
3. **添加误差棒**：涉及实验数据时，始终添加误差棒以展示数据可靠性
4. **趋势线辅助**：散点图添加趋势线，显示拟合方程和 R² 值
5. **暂存多版本**：每次调整后都暂存快照，方便对比和回溯

### 排版与导出

1. **使用期刊预设**：在投稿时，先选择目标期刊的尺寸预设，确保图片符合排版要求
2. **对齐辅助线**：排列多个子图时启用对齐辅助线，确保间距一致
3. **自动编号**：使用子图自动编号功能，保持编号格式统一
4. **高 DPI 导出**：投稿时使用 2x 或更高分辨率导出 PNG
5. **矢量图投稿**：需要无损缩放时，使用 Desktop 版导出 SVG 或 PDF

### 工作区管理

1. **定期保存**：养成 `Ctrl+S` 的习惯，防止意外丢失
2. **工作区备份**：重要节点保存为独立的 `.json` 文件，作为版本快照
3. **跨版本使用**：`.json` 和 `.spf` 文件在 Lite 与 Desktop 之间通用
