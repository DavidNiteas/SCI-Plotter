## 版本对照

SCI-Plotter 提供 Lite（浏览器版）和 Desktop（桌面版）两种使用方式，共用同一套前端代码，数据格式完全兼容。

| 功能 | Lite | Desktop |
|------|------|---------|
| CSV 导入 | ✅ 浏览器上传 | ✅ 系统文件对话框 |
| Excel 导入 | ✅ 需联网加载 SheetJS | ✅ 内置支持 |
| 数据表管理 | ✅ | ✅ |
| 分析工作台 | ✅ | ✅ |
| 统计分析（12 种方法） | ✅ JS 引擎 | ✅ Python 后端 |
| 子图编辑 (ECharts) | ✅ | ✅ |
| 主图排版 (Fabric.js) | ✅ | ✅ |
| 工作区保存/打开 | ✅ 下载/上传 | ✅ 系统对话框 |
| 自动保存与恢复 | ❌ | ✅ |
| PNG/JPEG 导出 | ✅ | ✅ |
| SVG/PDF 矢量导出 | ❌ | ✅ |
| PDF 报告生成 | ❌ | ✅ |
| 打印到物理打印机 | ❌ | ✅ |
| 插件扩展 | ❌ | ✅ |
| 零安装运行 | ✅ | ❌ 需 `pip install` |

## 图表模板

共 18 种图表模板，基于 Apache ECharts 渲染，支持实时交互（缩放、悬浮提示）。

### 基础图表

| 模板 | 标识符 | 说明 | 数据列映射 | Demo |
|------|--------|------|------------|------|
| 散点图 | `scatter` | 两列数值的分布关系，支持分组着色 | X(数值) Y(数值) 分组(分类) | `scatter_demo.csv` |
| 折线图 | `line` | 趋势变化展示，第一列作 X 轴 | X(任意) Y(数值) 分组(分类) | `line_demo.csv` |
| 柱状图 | `bar` | 数值比较 | X(任意) Y(数值) 分组(分类) | `bar_demo.csv` |
| 直方图 | `histogram` | 频率分布 | X(数值) | `histogram_demo.csv` |
| 面积图 | `area` | 面积堆叠趋势展示 | X(任意) Y(数值) 分组(分类) | — |

### 分组与堆叠

| 模板 | 标识符 | 说明 | 数据列映射 |
|------|--------|------|------------|
| 分组柱状图 | `group_bar` | 多组并列柱状比较 | X(分类) Y(数值) 分组(分类) |
| 分组折线图 | `group_line` | 多组折线对比 | X(分类) Y(数值) 分组(分类) |
| 堆叠柱状图 | `stacked_bar` | 分类数据堆叠 | X(分类) Y(数值) 分组(分类) |

### 统计图表

| 模板 | 标识符 | 说明 | 数据列映射 | Demo |
|------|--------|------|------------|------|

| 小提琴图 | `violin` | 分布密度与箱线图结合 | 分组(分类) 值(数值) | — |

## 数据管理

### 导入格式

| 格式 | 扩展名 | Lite | Desktop | 说明 |
|------|--------|------|---------|------|
| CSV | `.csv`, `.txt` | ✅ | ✅ | 自动检测分隔符（逗号/制表符/分号/竖线） |
| Excel | `.xlsx`, `.xls` | ✅ | ✅ | 多工作表自动拆分为多个数据表 |

### 表格操作

| 操作 | 说明 |
|------|------|
| 单元格编辑 | 双击编辑，Enter 确认 |
| 选区 | 单击 + 拖拽、Shift+点击 扩展选区 |
| 复制/剪切/粘贴 | 支持跨表操作 |
| 全选 | 选中全部单元格 |
| 查找替换 | 文本搜索与替换 |
| 新建空表 | 手动创建并逐行录入 |
| 重命名 | 双击表名修改 |
| 删除 | 弹出确认对话框 |
| 导出单表 CSV | 导出当前选中的表 |
| 导出全部数据 | 所有表打包为 JSON |

### CSV 解析特性

- 自动检测分隔符：逗号 `,`、制表符 `\t`、分号 `;`、竖线 `|`
- 正确处理引号内的分隔符和转义字符
- 第一行自动识别为列名
- 数字字段自动转为 `number` 类型
- 空单元格存储为 `null`

## 分析工作台

### 数据预处理

#### 过滤

- 支持多条件组合
- 运算符：等于、不等于、大于、小于、大于等于、小于等于、包含、不包含、为空、非空

#### 排序

- 按任意列升序或降序排列
- 实时预览排序结果

#### 缺失值处理

| 方法 | 适用列类型 |
|------|-----------|
| 删除含缺失值的行 | 全部 |
| 填充均值 | 数值列 |
| 填充中位数 | 数值列 |
| 填充众数 | 全部 |
| 填充固定值 | 全部 |
| 前向填充 | 全部 |
| 后向填充 | 全部 |

#### 数据标准化

| 方法 | 公式/说明 |
|------|----------|
| Z-score | `(x - μ) / σ` |
| Min-Max | `(x - min) / (max - min)` → [0, 1] |
| MaxAbs | `x / max(|x|)` |
| Robust | 基于中位数和四分位距 |
| Log 变换 | `ln(x)` |

### 计算新列

| 模式 | 说明 |
|------|------|
| 双列运算 | 加 `+`、减 `-`、乘 `×`、除 `÷` |
| 单列函数 | `abs`, `sqrt`, `square`, `log`, `log10`, `exp`, `sin`, `cos`, `tan`, `floor`, `ceil`, `round` |
| 统计变换 | 基于列统计量 |

### 统计分析方法

共 12 种统计方法，Lite 版使用纯 JavaScript 引擎实现，Desktop 版使用 Python（scipy、pandas）后端。

| 方法 | 类别 | 输入要求 | 输出 |
|------|------|----------|------|
| 描述性统计 | 描述 | ≥1 列数值 | 均值、标准差、最小值、Q1、中位数、Q3、最大值 |
| 独立样本 t 检验 | 假设检验 | 1 列数值 + 1 列二分类 | t 值、p 值、自由度、置信区间 |
| Mann-Whitney U 检验 | 非参数检验 | 1 列数值 + 1 列二分类 | U 值、p 值 |
| Wilcoxon 符号秩检验 | 非参数检验 | 2 列数值（配对） | W 值、p 值 |
| 单因素方差分析 | 假设检验 | 1 列数值 + 1 列分类 | F 值、p 值 |
| Kruskal-Wallis 检验 | 非参数检验 | 1 列数值 + 1 列分类 | H 值、p 值 |
| 卡方独立性检验 | 假设检验 | 2 列分类 | χ² 值、p 值、自由度 |
| 简单线性回归 | 回归 | 2 列数值 | 斜率、截距、R²、p 值 |
| 多元线性回归 | 回归 | ≥2 列数值（1 因变量 + 多自变量） | 各系数、R²、调整 R²、F 值、p 值 |
| 相关矩阵 | 相关 | ≥2 列数值 | Pearson 相关系数矩阵 |
| 正态性检验 | 分布检验 | 1 列数值 | Shapiro-Wilk W 值、p 值 |
| 异常值检测 | 数据质量 | 1 列数值 | IQR 或 Z-score 方法标记异常点 |

分析结果同时提供**表格视图**和**图表视图**。

| Y 轴范围 | 手动最小值/最大值 |

### 误差棒

| 类型 | 参数 |
|------|------|

| 固定值 | 统一误差值 |

### 趋势线

| 类型 | 方程 | 附加选项 |
|------|------|----------|
| 线性 | `y = ax + b` | 显示方程、显示 R² |

### 显著性标注

- 支持添加 `*`, `**`, `***`, `ns` 等显著性标记
- 交互式操作：点击两个比较位置后输入标注文本
- 自动绘制连接线

### 绘图工具

| 工具 | 说明 |
|------|------|
| 选择 | 选择与移动图形 |
| 矩形 | 拖拽绘制矩形 |
| 圆形 | 拖拽绘制椭圆 |
| 直线 | 拖拽绘制直线 |

| 文本 | 点击位置输入文本 |

## 导出与保存

### 文件格式

| 格式 | 扩展名 | 类型 | Lite | Desktop | 说明 |
|------|--------|------|------|---------|------|
| 工作区备份 | `.json` | JSON | ✅ download | ✅ 文件对话框 | 全量备份：数据表 + 快照 + 主图 |
| 可编辑图 | `.spf` | JSON | ✅ download | ✅ 文件对话框 | 自包含，含主图图层和所需快照 |
| 全部数据表 | `.json` | JSON | ✅ download | ✅ 文件对话框 | 仅数据表 |
| 单表 CSV | `.csv` | CSV | ✅ download | ✅ 文件对话框 | 当前选中表 |
| PNG | `.png` | 光栅图 | ✅ | ✅ | 支持 1x/2x/3x/4x DPI |
| JPEG | `.jpeg` | 光栅图 | ✅ | ✅ | 有损压缩 |
| SVG | `.svg` | 矢量图 | ❌ | ✅ | 无限缩放 |
| PDF | `.pdf` | 矢量图 | ❌ | ✅ | 论文投稿 |
| PDF 报告 | `.pdf` | 文档 | ❌ | ✅ | reportlab 生成完整报告 |

### 自动保存（Desktop）

- 自动保存到 `~/.sci-plotter/autosave.json`
- 启动时自动检测并提示恢复
- 无需手动操作

### 版本兼容性

- `.json` 和 `.spf` 文件包含 `version` 字段
- Lite 与 Desktop 版之间完全兼容
- 版本不匹配时控制台警告但尝试兼容加载

### 内部数据格式

**数据表**：
```json
{
  "id": "sp_...",
  "name": "表名",
  "headers": ["列名1", "列名2"],
  "rows": [[1, "text"], [null, 3.14]],
  "createdAt": 1700000000000,
  "source": "csv"
}
```

**工作区文件 (`.json`)**：
```json
{
  "format": "sci-plotter-workspace",
  "version": "1.1.0",
  "tables": [...],
  "snapshots": [...],
  "mainfigure": {...},
  "settings": {...}
}
```

**可编辑图文件 (`.spf`)**：
```json
{
  "format": "sci-plotter-figure",
  "version": "1.1.0",
  "snapshots": [...],
  "layers": [...],
  "canvasSize": {...}
}
```
