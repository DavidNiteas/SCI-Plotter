# 主图排版

> 基于 Fabric.js 的自由画布，支持多图组合、精确对齐和期刊级排版。

## 画布设置

### 期刊尺寸预设

| 期刊 | 单栏 (宽×高 px) | 双栏 (宽×高 px) |
|------|-----------------|-----------------|
| Nature | 336 × 448 | 692 × 519 |
| Science | 215 × 287 | 454 × 340 |
| PLOS | 321 × 428 | 673 × 505 |
| IEEE | 336 × 448 | 695 × 522 |
| Elsevier | 340 × 454 | 718 × 539 |
| ACS | 314 × 419 | 673 × 505 |

也可自定义画布宽度和高度。

### 背景色

支持自定义画布背景颜色。

---

## 添加子图

### 从快照库拖入

左侧快照库显示所有已暂存的子图，直接拖拽到画布上即可添加。

### 从子图编辑器发送

在子图编辑页点击**「发送到主图」**，自动切换到主图页并添加子图。

---

## 图层管理

右侧图层列表显示画布上所有对象：

| 操作 | 说明 |
|------|------|
| 选择 | 点击图层名选中对应画布对象 |
| 排序 | 拖拽图层调整前后层叠顺序 |
| 锁定 | 锁定图层防止误操作 |
| 删除 | 删除图层及其画布对象 |
| 重命名 | 双击图层名修改名称 |

---

## 画布操作

| 操作 | 方式 |
|------|------|
| 选择对象 | 点击画布上的对象 |
| 移动对象 | 拖拽对象 |
| 缩放对象 | 拖拽对象四角的缩放手柄 |
| 旋转对象 | 拖拽对象顶部的旋转手柄 |
| 画布缩放 | 使用缩放控件或鼠标滚轮（10%~500%） |
| 画布平移 | 按住 `Space` + 拖拽鼠标 |
| 删除对象 | 选中后按 `Delete` |

---

## 对齐辅助

拖拽对象时自动显示对齐辅助线，帮助精确对齐其他对象或画布边缘/中心。可通过工具栏开关启用/禁用。

---

## 子图自动编号

| 选项 | 说明 |
|------|------|
| 编号格式 | `(a)`, `(A)`, `a)`, `A)`, `a.`, `Fig.a` 等 |
| 编号字号 | 可自定义编号字体大小 |
| 编号位置 | 子图的左上角等位置 |

添加新子图时自动递增编号。

---

## 绘图工具

主图排版页同样提供矩形、圆形、直线、箭头、文本等绘图工具，用于在画布上添加辅助标注。

---

## 属性面板

选中画布上的对象后，属性面板显示并可编辑：

- 位置 (X, Y)
- 尺寸 (宽, 高)
- 旋转角度
- 透明度
