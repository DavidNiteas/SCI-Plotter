# 数据管理

> 数据管理是整个工作流的起点，负责数据的导入、编辑、组织与导出。

## 导入数据

### CSV 文件

点击左侧**「导入 CSV」**按钮，选择 CSV 文件。系统会自动检测分隔符类型：

- 逗号 `,`、制表符 `\t`、分号 `;`、竖线 `|`

| 规则 | 说明 |
|------|------|
| 列名 | 第一行自动识别为列名 |
| 数值 | 数字字段自动转为 `number` 类型 |
| 空值 | 空单元格存储为 `null` |
| 引号 | 正确处理引号内的分隔符和转义字符 |

### Excel 文件

点击**「导入 Excel」**按钮，选择 `.xlsx` 或 `.xls` 文件。多个工作表会自动创建为独立的数据表。

> Lite 版需要网络连接以加载 SheetJS 库；Desktop 版内置支持。

### 手动新建

点击**「新建空表」**按钮，输入表名即可创建空白数据表。

## 编辑数据

| 操作 | 方式 |
|------|------|
| 编辑单元格 | 双击单元格，输入新值，按 `Enter` 确认 |
| 选区 | 单击选中，拖拽或 `Shift+点击` 扩展选区 |
| 复制/剪切/粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 全选 | `Ctrl+A` |
| 删除内容 | 选中后按 `Delete` |
| 查找替换 | `Ctrl+F` 打开查找替换面板 |

## 管理数据表

| 操作 | 方式 |

## 分析工作台

分析工作台提供数据预处理和统计分析功能。

### 基本操作

1. 在**「源数据表」**下拉框中选择要分析的数据表
2. 在左侧列表中**勾选需要分析的列**

### 数据预处理

| 功能 | 说明 |
|------|------|
| 过滤 | 按条件筛选行（支持等于、不等于、大于、小于、包含等运算符） |
| 排序 | 按指定列升序/降序 |
| 缺失值处理 | 删除行、填充均值/中位数/众数/固定值、前后向填充 |
| 数据标准化 | Z-score、Min-Max、MaxAbs、Robust、Log 变换 |
| 计算新列 | 双列运算（加减乘除）、单列函数、统计变换 |

### 统计分析

共 12 种统计方法：

| 方法 | 说明 | 参数要求 |
|------|------|----------|
| 描述性统计 | 均值、标准差、最小/最大值、四分位数 | ≥1 列数值 |
| 独立样本 t 检验 | 两组均值差异检验 | 1 列数值 + 1 列二分类 |
| Mann-Whitney U 检验 | 非参数两组差异 | 1 列数值 + 1 列二分类 |
| Wilcoxon 符号秩检验 | 配对样本非参数检验 | 2 列数值 |
| 单因素方差分析 | 多组均值比较 | 1 列数值 + 1 列分类 |
| Kruskal-Wallis 检验 | 非参数多组比较 | 1 列数值 + 1 列分类 |
| 卡方独立性检验 | 分类变量关联检验 | 2 列分类 |
| 简单线性回归 | 单自变量线性拟合 | 2 列数值 |
| 多元线性回归 | 多自变量线性拟合 | ≥2 列数值 |
| 相关矩阵 | 变量间相关系数 | ≥2 列数值 |
| 正态性检验 | 数据正态性评估 | 1 列数值 |
| 异常值检测 | IQR 或 Z-score 识别异常值 | 1 列数值 |

> Lite 版使用 JavaScript 引擎，Desktop 版使用 Python 后端（scipy、pandas）。
