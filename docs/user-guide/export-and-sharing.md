# 导出与分享

> 多种导出格式满足从屏幕展示到论文出版的不同需求。

## 导出格式汇总

| 格式 | 扩展名 | 说明 | Lite | Desktop |
|------|--------|------|------|---------|
| 工作区备份 | `.json` | 全量备份（数据表+快照+主图），恢复继续编辑 | ✅ 下载 | ✅ 文件对话框 |
| 可编辑图 | `.spf` | 自包含格式（主图图层+所需快照） | ✅ 下载 | ✅ 文件对话框 |
| 全部数据表 | `.json` | 仅数据表 | ✅ 下载 | ✅ 文件对话框 |
| 单表 CSV | `.csv` | 当前选中表 | ✅ 下载 | ✅ 文件对话框 |
| PNG 图片 | `.png` | 光栅图，支持 1x~4x DPI | ✅ | ✅ |
| JPEG 图片 | `.jpeg` | 有损压缩光栅图 | ✅ | ✅ |
| SVG 矢量图 | `.svg` | 无限缩放矢量图 | ❌ | ✅ |
| PDF 矢量图 | `.pdf` | 论文投稿用 | ❌ | ✅ |
| PDF 报告 | `.pdf` | 包含图表说明的完整报告 | ❌ | ✅ |

---

## 图片导出

点击顶部**「导出」**按钮或按 `Ctrl+E`：

1. 选择导出格式（PNG / JPEG）
2. 选择 DPI 倍数：
   - **1x**：标准分辨率，适合屏幕展示
   - **2x**：高分辨率，适合论文投稿
   - **3x / 4x**：超高分辨率，适合大幅面印刷
3. 点击导出

## 工作区保存与加载

### 保存工作区

| 方式 | 说明 |
|------|------|
| `Ctrl + S` | 快捷键保存 |
| 顶部「保存」按钮 | 点击保存 |

工作区 `.json` 文件包含：

- 所有数据表（含 headers、rows）
- 子图快照库（含缩略图和完整 ECharts 配置）
- 主图画布状态（图层、对象位置、尺寸）
- 全局设置

### 打开工作区

点击顶部**「打开工作区」**按钮，选择之前保存的 `.json` 文件。

### 可编辑图文件 (.spf)

`.spf` 文件是自包含的描述性格式，仅包含主图图层和所需的快照数据，适合在设备之间传递单个排版好的图。

---

## 版本兼容性

- `.json` 和 `.spf` 文件包含 `version` 字段
- Lite 与 Desktop 版之间完全兼容
- 版本不匹配时控制台发出警告，但会尝试兼容加载

---

## 自动保存（仅 Desktop）

Desktop 版会将工作区自动保存到 `~/.sci-plotter/autosave.json`。下次启动时如有自动保存数据，会提示是否恢复。
