# 样式与自定义

> 调整配色方案、字体、坐标轴、误差棒和趋势线，让图表满足出版要求。

## 配色方案

内置 14 种科研配色方案：

| 配色 | 标识符 | 说明 |
|------|--------|------|
| 学术蓝 | `academic` | 默认配色，蓝色系 |
| Nature | `nature` | Nature 期刊风格 |
| Science | `science` | Science 期刊风格 |
| Cell | `cell` | Cell 期刊风格 |
| Lancet | `lancet` | Lancet 期刊风格 |
| JAMA | `jama` | JAMA 期刊风格 |
| Viridis | `viridis` | 感知均匀色图 |
| Seaborn | `seaborn` | Seaborn 默认风格 |
| Tableau 10 | `tableau10` | Tableau 默认色板 |
| Okabe-Ito | `okabe_ito` | 色盲友好配色 |
| 暖色 | `warm` | 红橙暖色调 |
| 冷色 | `cool` | 蓝绿冷色调 |
| 柔和色 | `pastel` | 柔和粉彩色调 |
| 黑白 | `monochrome` | 灰度单色 |

配色方案同时影响 ECharts 主题（坐标轴、图例、提示框颜色）。

## 字体与字号

| 配置项 | 说明 |
|--------|------|
| 字体族 | Arial, Times New Roman, Helvetica, Georgia, Courier New, Verdana, Tahoma, Trebuchet MS, Palatino, Bookman |

## 宽高比

支持预设和自定义宽高比：`4:3`、`16:9`、`1:1`、`3:4`、自定义。

---

## 坐标轴配置

| 选项 | 说明 |
|------|------|
| 图表标题 | 设置标题文本和显示/隐藏 |
| X/Y 轴标签 | 设置坐标轴名称 |
| X/Y 轴范围 | 手动设置最小/最大值 |
| X/Y 轴类型 | 数值轴 (value) 或对数轴 (log) |
| 网格线 | 显示/隐藏网格线 |
| 刻度线 | 显示/隐藏 X、Y 轴刻度 |

---

## 误差棒

展开**「误差棒」**面板启用，支持以下类型：

| 类型 | 说明 | 适用模板 |
|------|------|----------|
| 数据列 (`column`) | 指定正/负误差对应的数据列 | scatter, line, bar, group_bar, group_line |
| 固定值 (`fixed`) | 所有数据点使用统一的固定误差值 | scatter, line, bar |
| 百分比 (`percent`) | 按数据值的百分比计算误差 | scatter, line, bar |
| 标准差 (`std`) | 按数据的标准差计算 | group_bar, group_line |

支持 Y 轴和 X 轴方向的误差棒。

---

## 趋势线

展开**「趋势线」**面板启用，支持以下回归类型：

| 类型 | 方程 | 适用模板 |
|------|------|----------|
| 线性 (`linear`) | `y = ax + b` | scatter, line |
| 多项式 (`polynomial`) | `y = aₙxⁿ + ... + a₀`，可指定阶数（2~10） | scatter, line |
| 指数 (`exponential`) | `y = a·eᵇˣ` | scatter, line |
| 对数 (`logarithmic`) | `y = a·ln(x) + b` | scatter, line |
| 幂函数 (`power`) | `y = a·xᵇ` | scatter, line |

### 附加选项

| 选项 | 说明 |
|------|------|
| 显示方程 | 在图表上显示拟合方程 |
| 显示 R² | 在图表上显示决定系数 |
| 自定义样式 | 可调整趋势线颜色、线宽（1~10 px）和线型（实线/虚线/点线） |

---

## 显著性标注

支持在图表上添加显著性标记（如 `*`, `**`, `***`, `ns`）：

1. 点击工具栏的显著性标注按钮
2. 依次点击两个要比较的位置
3. 输入标注文本
4. 自动绘制连接线

---

## 绘图工具

图表下方的绘图工具栏提供以下标注工具：

| 工具 | 说明 |
|------|------|
| 选择 | 选择并移动已绘制的图形 |
| 矩形 | 拖拽绘制矩形 |
| 圆形 | 拖拽绘制椭圆 |
| 直线 | 拖拽绘制直线 |
| 箭头 | 拖拽绘制带箭头的直线 |
| 文本 | 点击位置输入文本标注 |

每个图形支持调整颜色、线宽、透明度。
