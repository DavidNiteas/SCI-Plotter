## 版本概览

| 维度 | Lite 版 | Desktop 版 |
|------|---------|------------|
| 运行方式 | 浏览器打开 `index.html` | `pixi run dev` 启动桌面窗口 |
| 安装要求 | 无，零安装 | Python >= 3.10 + pixi 环境 |
| 前端框架 | 原生 JavaScript + CDN | 同左（通过 PyWebView 嵌入） |
| 图表渲染 | Apache ECharts 5.5.0 | 同左 |
| 画布引擎 | Fabric.js 5.3.0 | 同左 |
| 后端语言 | 无 | Python（pandas、scipy、matplotlib） |
| 数据存储 | 浏览器内存 | 浏览器内存 + 本地文件系统 |
| 离线使用 | ✅ 完全离线（Excel 导入除外） | ✅ 完全离线 |

## 如何选择

### 选择 Lite 版

- 需要快速出图，不想安装任何软件
- 在实验室公共电脑或平板上使用
- 不需要 SVG/PDF 矢量导出
- 主要做数据可视化和简单统计
- 需要在不同设备间传递工作区文件

### 选择 Desktop 版

- 需要论文投稿级别的矢量图（SVG/PDF）输出
- 需要 PDF 报告生成功能
- 希望使用 Python 后端获得更高的统计计算精度
- 需要自动保存功能，防止数据丢失
- 需要通过插件扩展功能
- 频繁使用，需要系统文件对话框的便捷操作

### 两者兼用

两套版本的数据格式完全兼容，推荐的工作方式是：

1. 在 Lite 版中快速探索数据、选择图表样式
2. 保存工作区 `.json` 文件
3. 在 Desktop 版中打开，进行精细调整和矢量导出

## 数据格式兼容性

### 工作区文件 (`.json`)

```json
{
  "format": "sci-plotter-workspace",
  "version": "1.1.0",
  "tables": [],
  "snapshots": [],
  "mainfigure": {},
  "settings": {}
}
```

Lite 与 Desktop 版之间完全兼容。版本不匹配时控制台会发出警告，但会尝试兼容加载。

### 可编辑图文件 (`.spf`)

```json
{
  "format": "sci-plotter-figure",
  "version": "1.1.0",
  "snapshots": [],
  "layers": [],
  "canvasSize": {}
}
```

Lite 与 Desktop 版之间完全兼容。

### 数据表文件 (`.json`)

仅包含数据表的精简格式，用于跨版本传递数据。

## 统计引擎差异

Lite 版内置了完整的 JavaScript 统计引擎，所有 12 种统计方法均可在浏览器中独立运行，无需网络连接。Desktop 版使用 Python 后端（scipy、pandas）执行分析，具有更高的数值精度和更强的计算能力。

| 方面 | Lite（JS 引擎） | Desktop（Python 后端） |
|------|-----------------|----------------------|
| 计算精度 | 双精度浮点（~15 位有效数字） | 双精度浮点 + 任意精度可选 |
| 大数据集 | 受浏览器内存限制 | 受系统内存限制，通常更宽裕 |
| 依赖 | 无外部依赖 | scipy、pandas、numpy |
| 速度 | 小数据集更快（无网络开销） | 大数据集更快（优化算法） |
| 结果一致性 | 两种实现经过交叉验证，统计结论一致 | 同左 |

## 混合使用建议

### 从 Lite 迁移到 Desktop

1. 在 Lite 版中导出工作区（`Ctrl+S`）
2. 在 Desktop 版中打开工作区文件
3. 所有数据表、快照、主图状态完整恢复

### 从 Desktop 迁移到 Lite

1. 在 Desktop 版中保存工作区
2. 在 Lite 版中通过「打开工作区」加载
3. 注意：SVG/PDF 导出和插件功能在 Lite 版中不可用

### 团队协作场景

- 团队成员可以自由选择版本
- 工作区文件可以在版本间无缝传递
- 推荐使用统一的配色方案和字体设置，确保跨版本视觉一致性
