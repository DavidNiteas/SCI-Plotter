## 安装与启动

### 环境要求

- Python >= 3.10
- pixi 环境管理器

### 安装步骤

```bash
cd sci-plotter
pixi install
```

### 启动方式

```bash
# 开发模式（直接引用前端源文件，修改后刷新即可生效）
pixi run dev

# 开发模式并指定端口
pixi run python -m sci_plotter --dev --port 8080

# 启用调试模式（允许右键检查元素）
pixi run python -m sci_plotter --debug
```

Desktop 版启动后会打开一个 1400×900 的桌面窗口，界面与 Lite 版完全一致。

## 系统文件对话框

Desktop 版使用操作系统原生的文件对话框替代浏览器的 `<input type="file">`，提供更自然的文件操作体验。

### 打开文件

| 操作 | 对话框类型 | 支持格式 |
|------|-----------|----------|
| 导入 CSV | 系统打开对话框 | `.csv`, `.txt` |
| 导入 Excel | 系统打开对话框 | `.xlsx`, `.xls` |
| 打开工作区 | 系统打开对话框 | `.json`, `.spf` |

### 保存文件

| 操作 | 默认文件名 | 对话框类型 |
|------|-----------|-----------|
| 保存工作区 | `workspace.json` | 系统保存对话框 |
| 保存可编辑图 | `figure.spf` | 系统保存对话框 |
| 导出全部数据 | `tables.json` | 系统保存对话框 |
| 导出单表 CSV | `表名.csv` | 系统保存对话框 |
| 导出 PNG | `figure.png` | 系统保存对话框 |
| 导出 SVG | `figure.svg` | 系统保存对话框 |
| 导出 PDF | `figure.pdf` | 系统保存对话框 |

与 Lite 版的浏览器下载相比，系统对话框支持：
- 自由选择保存位置
- 直接覆盖已有文件
- 文件类型过滤
- 最近访问目录记忆（最多 20 个）

## 自动保存与恢复

Desktop 版会自动将工作区状态保存到本地文件，防止意外关闭导致数据丢失。

### 工作原理

| 阶段 | 行为 |
|------|------|
| 运行中 | 工作区变更时自动保存到 `~/.sci-plotter/autosave.json` |
| 下次启动 | 检测到自动保存文件后，弹窗询问是否恢复 |
| 恢复 | 选择「恢复」后加载自动保存数据，工作区回到上次状态 |
| 放弃 | 选择「放弃」后清除自动保存文件，从空白工作区开始 |

### 保存内容

自动保存文件包含完整的工作区状态：

- 所有数据表（headers、rows）
- 子图快照库（含缩略图和 ECharts 配置）
- 主图画布状态（图层、对象位置、尺寸、旋转）
- 全局设置

### 存储位置

自动保存文件位于用户主目录下的 `.sci-plotter` 文件夹中：

```
~/.sci-plotter/
├── autosave.json    # 自动保存数据
└── plugins/         # 插件目录
```

## Python 统计分析

Desktop 版的统计分析由 Python 后端（scipy、pandas、numpy）执行，相比 Lite 版的 JavaScript 引擎具有更高的数值精度和更强的计算能力。

### 支持的方法

| 方法 | 类别 | Python 实现 |
|------|------|------------|
| 描述性统计 | 描述 | pandas `describe()` |
| 独立样本 t 检验 | 假设检验 | scipy `ttest_ind()` |
| Mann-Whitney U 检验 | 非参数检验 | scipy `mannwhitneyu()` |
| Wilcoxon 符号秩检验 | 非参数检验 | scipy `wilcoxon()` |
| 单因素方差分析 | 假设检验 | scipy `f_oneway()` |
| Kruskal-Wallis 检验 | 非参数检验 | scipy `kruskal()` |
| 卡方独立性检验 | 假设检验 | scipy `chi2_contingency()` |
| 简单线性回归 | 回归 | scipy `linregress()` |
| 多元线性回归 | 回归 | numpy 最小二乘法 |
| 相关矩阵 | 相关 | pandas `corr()` |
| 正态性检验 | 分布检验 | scipy `shapiro()` |
| 异常值检测 | 数据质量 | IQR / Z-score 方法 |

### 执行流程

1. 前端将数据表（headers + rows）和分析参数序列化为 JSON
2. 通过 PyWebView 桥接调用 Python `analyze_data()` 方法
3. Python 端构建 pandas DataFrame 并执行分析
4. 分析结果以 JSON 格式返回前端
5. 前端渲染结果表格和图表

### 相比 Lite 版的优势

| 方面 | Lite（JS） | Desktop（Python） |
|------|-----------|-------------------|
| 数值精度 | 双精度浮点 | 双精度浮点 + 任意精度可选 |
| 大数据集 | 受浏览器内存限制 | 受系统内存限制，通常更宽裕 |
| 计算速度 | 小数据集更快 | 大数据集更快 |
| 扩展性 | 固定算法 | 可通过插件扩展 |

## 矢量图导出

Desktop 版使用 matplotlib 将主图画布内容导出为 SVG 或 PDF 矢量图，适合论文投稿和无损缩放。

### SVG 导出

- 格式：Scalable Vector Graphics
- 特点：XML 文本格式，可被浏览器和矢量编辑软件打开
- 适用场景：网页嵌入、矢量编辑软件二次加工
- 扩展名：`.svg`

### PDF 导出

- 格式：Portable Document Format
- 特点：通用矢量文档格式
- 适用场景：论文投稿、打印输出
- 扩展名：`.pdf`

### 导出流程

1. 点击顶部「导出」按钮
2. 选择 SVG 或 PDF 格式
3. 系统弹出保存对话框
4. 选择保存位置并确认

### 导出内容

导出文件包含主图画布上的所有可见对象：

| 对象类型 | 导出方式 |
|---------|---------|
| 子图（图片） | 矩形占位框 |
| 文本 | matplotlib 文本对象 |
| 矩形 | matplotlib Rectangle |
| 圆形 | matplotlib Circle |

## PDF 报告生成

Desktop 版使用 reportlab 生成包含图表信息的 PDF 报告文档。

### 报告内容

| 页面 | 内容 |
|------|------|
| 封面 | 标题、画布尺寸信息 |
| 后续页面 | 图表说明和数据摘要 |

### 生成方式

1. 点击顶部「导出」按钮
2. 选择「PDF 报告」格式
3. 系统弹出保存对话框
4. 选择保存位置并确认

PDF 报告适合在学术汇报和实验记录中使用，将图表和分析结论整合为一份完整的文档。

## 插件系统

Desktop 版支持通过 Python 插件扩展功能，插件在用户本地运行，具备当前进程的全部权限。

### 插件目录

```
~/.sci-plotter/plugins/
```

### 插件格式

插件为标准的 `.py` Python 文件，放置在插件目录中即可被自动发现。

### 加载机制

| 阶段 | 行为 |
|------|------|
| 启动时 | 扫描 `~/.sci-plotter/plugins/` 目录 |
| 发现 | 识别所有 `.py` 文件 |
| 加载 | 通过 `importlib` 动态加载为 Python 模块 |

### 编写插件

插件文件放置在 `~/.sci-plotter/plugins/` 目录下，例如 `my_plugin.py`。插件会在 Desktop 版启动时自动加载。

### 安全注意

- 插件在用户本地运行，具备当前 Python 进程的全部权限
- 仅加载用户主动放入插件目录的文件
- 建议审查第三方插件的代码内容

## 开发者模式

Desktop 版提供开发者模式，方便调试和扩展。

### 启动参数

| 参数 | 说明 |
|------|------|
| `--dev` | 启用开发模式，直接引用 `sci-plotter-lite/` 目录的前端源文件 |
| `--debug` | 启用调试模式，允许右键检查元素、打开开发者工具 |
| `--port <N>` | 指定内置 HTTP 服务端口（默认自动分配） |

### 开发模式优势

- 修改前端代码后无需同步资源，直接在窗口中刷新即可看到效果
- 通过内置 HTTP 服务避免 `file://` 协议的 CORS 限制
- 调试模式允许使用浏览器开发者工具检查页面元素

### 前端资源同步

非开发模式下，前端资源通过 `sync_assets.py` 脚本同步到 Desktop 包内：

```bash
pixi run python sci-plotter/scripts/sync_assets.py
```

## 技术依赖

Desktop 版在 Lite 版的前端依赖基础上，额外依赖以下 Python 库：

| 库 | 最低版本 | 用途 |
|---|----------|------|
| pywebview | 4.4 | 桌面窗口框架 |
| pandas | 2.0 | 数据分析与表格处理 |
| numpy | 1.24 | 数值计算 |
| scipy | 1.10 | 统计分析（t 检验、方差分析、回归等） |
| matplotlib | 3.7 | SVG/PDF 矢量图导出 |
| reportlab | 4.0 | PDF 报告生成 |
| Pillow | 10.0 | 图像处理 |
| chardet | 5.0 | 文件编码检测 |

所有依赖通过 pixi 自动管理，无需手动安装。
